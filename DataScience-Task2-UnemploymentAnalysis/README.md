## Project Overview

This project focuses on performing exploratory data analysis on unemployment data in India to identify regional and temporal trends, with particular attention to the changes in unemployment during the COVID-19 pandemic.

The analysis uses Python to clean, explore and visualise the unemployment dataset and extract meaningful observations from the data.

## Objective

The main objective of this project is to analyse unemployment patterns across different regions and over time and understand how unemployment conditions changed during the COVID-19 period.

## Tech Stack

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Dataset

Dataset used:

**Unemployment in India**

The dataset contains information related to:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## Analysis Performed

The following analyses were performed as part of the project:

- Data loading and initial inspection
- Shape and data type inspection
- Missing-value checking
- Date type conversion
- Removal of empty records
- Region-wise average unemployment analysis
- Month-wise unemployment trend analysis
- Time-series comparison of unemployment rates for three regions
- Top 10 regions with the highest average unemployment rate
- Correlation analysis using a heatmap
- Pre-COVID and post-COVID unemployment comparison
- Written observations based on the visualisations

## Key Findings

- Tripura recorded the highest average unemployment rate among the regions analysed.
- Haryana and Jharkhand also showed comparatively high average unemployment rates.
- Odisha recorded a comparatively lower average unemployment rate.
- Unemployment rates changed noticeably across the months covered by the dataset.
- Different regions showed different unemployment trends over time.
- The comparison between pre-COVID and post-COVID periods showed a noticeable change in unemployment conditions.
